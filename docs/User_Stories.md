# User Stories
## VK-Book Android

**Версия:** 2.0  
**Дата:** Октябрь 2026

## US-001: Поиск оборудования (Оператор)

**Как** оператор  
**Я хочу** быстро найти арматуру или прибор КИП по обозначению или назначению  
**Чтобы** выполнить операцию без задержек и ошибок

### Контекст
На объекте тысячи позиций оборудования. Обозначения пишутся по-разному: латиницей или кириллицей, с дефисами, точками, слэшами.

### Критерии приёмки
- [x] Поиск по всем столбцам или по выбранному столбцу
- [x] Совпадения подсвечиваются
- [x] Поиск находит позицию при разном написании обозначения
- [x] Один запрос применяется ко всем справочникам
- [x] Поиск работает без связи

### Приоритет: Высокий

---

## US-002: Место оборудования на плане (Обходчик)

**Как** обходчик  
**Я хочу** из справочника сразу открыть план с отмеченным оборудованием  
**Чтобы** не искать его на объекте вслепую

### Критерии приёмки
- [x] Нажатие на позицию открывает план или схему с отметкой
- [x] Если позиция есть на нескольких схемах — предлагается выбор
- [x] Масштабирование жестами и кнопками
- [x] Просмотр работает без связи

### Приоритет: Критический

---

## US-003: График проверок (Инженер)

**Как** инженер  
**Я хочу** видеть график проверок с подсветкой текущего часа  
**Чтобы** не пропустить регламентные проверки

### Критерии приёмки
- [x] Шкала на 36 часов с подсветкой часов текущей смены
- [x] Служебные проверки загружаются из Excel-графика
- [x] Личные задачи с собственными правилами повторения
- [x] Выбор нескольких часов и дат поднимает нужные задачи наверх

### Приоритет: Высокий

---

## US-004: Напоминания в течение смены (Сменный персонал)

**Как** сотрудник смены  
**Я хочу** получать напоминания о проверках своей смены и отмечать выполненные  
**Чтобы** ничего не пропустить и не отвлекаться на уже сделанное

### Критерии приёмки
- [x] Смена выбирается один раз, настройки сохраняются
- [x] Режим «один раз в начале смены» или «каждые N минут»
- [x] Можно выбрать, о каких проверках напоминать
- [x] Кнопка «Выполнено» в уведомлении — проверка не напоминает до конца смены
- [x] Можно отключить напоминания на сегодня
- [x] Напоминания приходят при закрытом приложении
- [x] Разрешения запрашиваются только при включении функции, с объяснением

### Приоритет: Высокий

---

## US-005: График смен (Сменный персонал)

**Как** сотрудник смены  
**Я хочу** видеть график сменности на год и на следующие годы  
**Чтобы** планировать личное время

### Критерии приёмки
- [x] Годовой календарь сменности бригад
- [x] Автоматический расчёт графика в обе стороны
- [x] Переход между годами, кнопка «Сегодня»
- [x] Масштабирование и подсветка выбранного дня

### Приоритет: Средний

---

## US-006: Актуальные базы без лишних действий (Сменный персонал)

**Как** сотрудник  
**Я хочу** обновлять базы одной кнопкой или автоматически  
**Чтобы** всегда работать с актуальными данными

### Критерии приёмки
- [x] Обновление идёт в фоне, приложение можно свернуть
- [x] Прогресс виден в уведомлении
- [x] Автоматическое обновление по расписанию — по выбору пользователя
- [x] Каждый файл проверяется по SHA-256

### Приоритет: Высокий

---

## US-007: Редактирование баз (Администратор)

**Как** администратор данных  
**Я хочу** редактировать справочники и отметки на схемах и публиковать изменения  
**Чтобы** все сотрудники получили актуальные данные

### Критерии приёмки
- [x] Доступ только по паролю, по умолчанию выключен
- [x] Редактор Excel-баз с отменой и повтором
- [x] Редактор отметок: добавление, перемещение, подпись, цвет, размер
- [x] Отправка баз на сервер с проверкой целостности
- [x] Обработка ошибок и повторные попытки при отправке

### Приоритет: Средний
