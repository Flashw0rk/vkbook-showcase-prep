# Product Requirements Document (PRD)
## VK-Book Android — мобильное рабочее место сменного персонала

**Версия:** 2.0  
**Дата:** Октябрь 2026  
**Автор:** Technical Product Manager

---

## 1. Проблема (Problem Statement)

### Текущее состояние

Операционная деятельность на промышленном объекте с непрерывным циклом работы сталкивается с типовыми проблемами.

#### 1.1 Информационный хаос
- Сменный персонал тратит много времени на поиск данных в бумажных журналах
- Excel-таблицы со справочниками хранятся в разных местах и в разных версиях
- Нет единого источника актуальных данных
- Высокая вероятность ошибок при ручном поиске информации

#### 1.2 Операционные риски
- Большое количество оборудования (тысячи позиций арматуры и КИП)
- Ошибки навигации у новичков из-за сложности объекта
- Ошибки по невнимательности у опытных сотрудников
- Пропуски регламентных проверок из-за плотного графика

#### 1.3 Нет данных на месте
- Нет мобильного доступа к схемам в помещениях без стационарных ПК
- Нет связи в экранированных помещениях
- Необходимость возвращаться к рабочему месту за информацией

## 2. Целевая аудитория

1. **Операторы и обходчики оборудования**
   - Ежедневная работа с оборудованием и регламентными проверками
   - Быстрый поиск позиций и их места на плане
   - Работа в помещениях без связи

2. **Инженерный персонал**
   - Контроль графиков проверок
   - Работа со справочниками и схемами

3. **Весь сменный персонал**
   - График сменности и планирование личного времени
   - Напоминания о проверках своей смены

4. **Администраторы данных**
   - Редактирование справочников и отметок на схемах
   - Публикация обновлённых баз на сервер

---

## 3. Цели продукта

### 3.1 Бизнес-цели
- **Сокращение времени поиска данных** — секунды вместо поиска по журналам и файлам
- **Снижение ошибок навигации** — место оборудования показывается на плане
- **Исключение пропусков проверок** — подсветка текущих задач и напоминания в смене
- **Единый источник данных** — все сотрудники получают одну актуальную версию баз

### 3.2 Технические цели
- **Offline-first** — все рабочие функции без связи
- **Производительность** на больших таблицах и схемах
- **Целостность данных** при обновлении
- **Надёжность** через автоматическое тестирование

## 4. Функциональные требования

### 4.1 Справочники «Арматура», «КИП», «Сигналы БЩУ»

**Требования:**
- Таблицы формируются из Excel-файлов заказчика
- Поиск по всем столбцам или по выбранному, подсветка совпадений
- Устойчивость поиска к разным вариантам записи обозначений (латиница/кириллица, «ё»/«е», дефисы, точки, слэши)
- Общий поисковый запрос для всех справочников
- Постраничная загрузка больших таблиц
- Переход от позиции к плану или схеме с отметкой оборудования
- «Сигналы БЩУ» доступны только администратору

**Критерии приёмки:**
- Поиск работает без связи с сервером
- Результаты появляются за секунды на таблицах в тысячи строк
- Ширина и порядок столбцов сохраняются

### 4.2 Схемы и планы

**Требования:**
- Просмотр PDF-планов и схем
- Отметка места оборудования (рамка, подпись, комментарий, цвет)
- Выбор схемы, если позиция есть на нескольких схемах
- Масштабирование с перерисовкой в высоком качестве

**Критерии приёмки:**
- Схема открывается сразу на нужной странице с отмеченным оборудованием
- Просмотр работает без связи

### 4.3 График проверок

**Требования:**
- Шкала на 36 часов с подсветкой часов текущей смены
- Служебные проверки из Excel-графика, личные задачи сотрудника
- Правила повторения: часы и дни недели, числа месяца, «N-й день недели месяца»
- Выбор нескольких часов и дат с поднятием подходящих задач наверх

**Критерии приёмки:**
- Подсветка текущего часа обновляется автоматически
- Личные задачи сохраняются на устройстве

### 4.4 Напоминания о проверках в смене

**Требования:**
- Выбор своей смены (бригады) один раз — настройки сохраняются
- Режимы: «один раз в начале смены» и «во время смены каждые N минут»
- Выбор проверок, о которых напоминать; отдельно — личные задачи
- Отдельное уведомление по каждой текущей проверке с кнопкой «Выполнено»
- Отмеченная проверка не напоминает до конца смены
- Отключение напоминаний на сегодня

**Критерии приёмки:**
- Напоминания приходят при закрытом приложении и после перезагрузки телефона
- Разрешения на уведомления запрашиваются только при включении функции, с объяснением

### 4.5 График смен

**Требования:**
- Годовой календарь сменности бригад
- Автоматический расчёт графика в обе стороны от любой даты
- Переход между годами, масштабирование, подсветка выбранного дня

**Критерии приёмки:**
- Расчёт года выполняется мгновенно
- График совпадает с утверждённым графиком сменности

### 4.6 Обновление данных

**Требования:**
- Ручное обновление баз в фоне с уведомлением о прогрессе
- Автоматическое фоновое обновление по расписанию (по выбору пользователя)
- Проверка каждого файла по SHA-256
- Работа со всеми базами без связи после первой загрузки

**Критерии приёмки:**
- Обновление продолжается при свёрнутом приложении
- Недокачанные файлы не заменяют рабочие (загрузка во временный файл и атомарная замена)

### 4.7 Администрирование

**Требования:**
- Доступ только по паролю, по умолчанию выключен
- Редактор Excel-баз с отменой и повтором
- Редактор отметок на схемах
- Отправка баз на сервер с проверкой целостности
- Перенос баз между устройствами через ZIP-архив

**Критерии приёмки:**
- Обычный пользователь не видит административных вкладок
- Неверный пароль не открывает доступ

### 4.8 Настройки
- 6 тем оформления, светлый и тёмный режимы
- Выбор видимых вкладок
- Настройки подключения к серверу и автообновления

## 7. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|

## 8. Заключение

VK-Book Android решает ключевые проблемы работы сменного персонала:

- быстрый поиск оборудования и его места на плане;
- контроль регламентных проверок с напоминаниями в течение смены;
- доступ ко всем данным без связи;
- единая актуальная версия баз для всех сотрудников.

Продукт находится в эксплуатации и готов к адаптации под другие объекты.
